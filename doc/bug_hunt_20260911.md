## Repeatable workflow

  state, steps, expected/actual values, impact, and evidence level.
- Run [the bug-hunt runner](../tools/ci/bug_hunt_README.md). It continues after
  failures, saves per-check logs, and emits JSON plus a Markdown dashboard.
- Keep `identity.json` with the report: source/configuration/import hashes, Git
  state, available server binaries, client archive priority/hashes, and loose files.
- Require the same regression to fail before the fix and pass after it. Track
  local validation and deployment separately.
- The added Windows preflight workflow exercises the actual PowerShell launcher
  on relevant pushes/PRs. Its commands passed locally; hosted CI has not run here.
